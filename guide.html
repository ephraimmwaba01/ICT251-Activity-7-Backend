Create or update

Send all four fields as JSON. Trimmed lengths are 3–80 for title, 2–40 for category and 5–300 for description. Status must be Pending, In progress or Completed. The database assigns the ID.

{
  "title": "Monitor flickers",
  "category": "Hardware",
  "description": "The practice lab monitor flickers when switched on.",
  "status": "Pending"
}

Errors return a JSON message. Invalid input returns 400, missing records or routes return 404 and unexpected server errors return 500.
